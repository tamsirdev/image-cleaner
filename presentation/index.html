The Problem

Images received from field officers often cause upload failures on WordPress:

Filenames with spaces and special characters
Gov't Revenue.jpg → Server rejects the file
Images too large for the server
5000x3000px photos → "Server cannot process the image"
Wrong file format
PNG files at 1.2MB when JPEG at 200KB would work

Result: Delayed publishing, frustrated staff, repeated re-uploads.

The Solution

A simple tool that fixes everything in one step:

Clean filenames — removes spaces, special characters, converts to lowercase
Resize to target — scales down to 1200x630 (WordPress featured image size)
Convert format — PNG to JPEG for smaller file sizes
Strip metadata — removes GPS, camera info, hidden data
Secure processing — files never leave your computer

Upload → Process → Download → Upload to WordPress

Features

  • Batch processing — handle 50 images at once
  • Smart resizing — maintains aspect ratio with padding
  • Multiple size presets — 1200x630, 1920x1080, 2560x1440, or custom
  • Format conversion — keep original, all JPEG, or all PNG
  • Quality control — adjustable JPEG compression
  • Preview — see before and after side by side
  • ZIP download — all images in one file
  • Security — EXIF stripped, magic bytes verified, files re-encoded

How to Use

1
Open the tool — Navigate to the Image Cleaner in your browser
2
Configure settings — Choose size preset, output format, and quality in the sidebar
3
Upload images — Drag and drop or click to browse your folder
4
Process — Click "Process Images" and wait for processing
5
Preview — Review the before/after results
6
Download — Get all cleaned images as a ZIP file
7
Upload to WordPress — Use the cleaned images on gambiadaily.gov.gm or gamna.gov.gm

Size Presets

Preset Dimensions Best For
Featured Image 1200 x 630 WordPress posts, social media sharing
Full HD 1920 x 1080 Banners, hero images, full-width display
2K 2560 x 1440 High-resolution displays, print-ready
Custom Your choice Specific requirements, social media sizes
Tip: For most WordPress posts, use 1200 x 630 (Featured Image). It's the standard size for post thumbnails and social media previews.

Security Features

Your images are processed safely:

Metadata Stripped
All EXIF data removed — GPS coordinates, camera serial numbers, dates, and hidden information are deleted.
Files Re-encoded
Images are decoded and re-encoded pixel by pixel — any embedded payloads or steganography are eliminated.
Magic Bytes Verified
File content is checked against actual image signatures — a .exe renamed as .jpg is rejected.
No Data Stored
All processing happens in your browser — no images are sent to any server.

Tips & Best Practices

Prepare your folder first
Keep all images in one folder before uploading to the tool.
Use consistent naming
Even before cleaning, try to name files descriptively: barrow-road-launch.jpg is better than IMG_20260819.jpg.
Check the preview
Always review the before/after preview before downloading — especially for important stories.
Match sizes to context
Use 1200x630 for post thumbnails, 1920x1080 for banners and hero images.
Maximum limits
20MB per file, 50 files per batch. Split larger batches if needed.
